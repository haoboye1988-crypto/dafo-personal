# DAFO personal

Herramienta web para la actividad **DAFO personal y mejora de soft skills** (IPOP · RA4 y RA5).

- Importa el informe PDF del test **.Clau** (Competències Clau) de Barcelona Activa y rellena automáticamente los niveles, la media y los puntos fuertes y débiles de cada competencia.
- Te guía por el DAFO (con preguntas guía), el plan de acción y la reflexión final.
- Comprueba los criterios de la rúbrica y genera el **PDF** para entregar en Moodle.

## Uso

Abre `index.html` en el navegador (o la versión publicada en GitHub Pages). Los datos se guardan solo en tu navegador; usa «Copia de seguridad (.json)» para pasarlos a otro dispositivo. Necesita conexión a internet para generar el PDF y leer el informe del test.
